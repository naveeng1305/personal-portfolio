## 🛠️ Setup Instructions

### 1. Extract the ZIP File
- Extract the portfolio files to your desired location
- Open the folder in Visual Studio Code

### 2. Add Your Photos
**IMPORTANT**: Replace the placeholder images with your actual photos:

- **Profile Photo** (`images/profile.jpg`):
  - Add a professional photo of yourself
  - Recommended size: 800x1000 pixels
  - Format: JPG or PNG
  
- **Project Image** (`images/iot-project.jpg`):
  - Add an image related to your IoT project
  - Recommended size: 1200x800 pixels
  - Format: JPG or PNG

### 3. Open in Browser
- Simply double-click `index.html` OR
- Right-click `index.html` → Open with → Your preferred browser
- Or use Live Server extension in VS Code for hot reload

### 4. Customize Content (Optional)
You can customize the content by editing `index.html`:
- Update project descriptions
- Add more projects
- Modify contact information
- Add social media links

## 📝 Customization Guide

### Changing Colors
Edit the CSS variables in `css/style.css` (lines 10-20):
```css
:root {
    --primary: #00d9ff;        /* Main accent color */
    --secondary: #ff6b35;      /* Secondary accent */
    --accent: #ffd23f;         /* Highlight color */
    /* ... other colors ... */
}
```

### Adding More Projects
Copy the `.project-main` section in `index.html` and modify the content.

### Modifying Skills
Update the skill items in the Skills section with your proficiency levels.

## 🌐 Deployment Options

### Option 1: GitHub Pages (Free)
1. Create a GitHub repository
2. Upload all files
3. Go to Settings → Pages
4. Select main branch → Save
5. Your site will be live at `https://yourusername.github.io/repository-name`

### Option 2: Netlify (Free)
1. Create account at netlify.com
2. Drag and drop your project folder
3. Get instant deployment with custom domain support

### Option 3: Vercel (Free)
1. Create account at vercel.com
2. Import your GitHub repository or upload files
3. Get deployed with automatic HTTPS

## 🔧 Troubleshooting

### Images not showing?
- Make sure image files are in the `images/` folder
- Check that filenames match exactly (case-sensitive)
- Verify image formats are JPG or PNG

### Styles not loading?
- Ensure `css/style.css` path is correct
- Clear browser cache (Ctrl+Shift+R)
- Check browser console for errors (F12)

### Form not working?
- The contact form opens your default email client
- Make sure your email client is configured
- Alternative: Users can email you directly
